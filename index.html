MLOps Pipeline for Predictive Maintenance

06/2026 — Present

Production-grade MLOps workflow for a machine-failure classifier (AI4I 2020, ~10,000 sensor records): training, experiment tracking and a model registry in MLflow, with automatic champion promotion.

  • Deployed via FastAPI, data-drift monitoring with Evidently, containerised with Docker Compose — 38 tests, ~90% coverage.

ML-Based Crypto Trading System

12/2025 — 03/2026

A modular end-to-end pipeline for algorithmic BTC/USDT trading: ~17,500 hourly data points, 16 engineered features (RSI, MACD, ATR).

  • Deployed on Binance Testnet — honestly documented 50% out-of-sample accuracy: public market features carried no real predictive edge.
